Slide Commit

A vanilla-JS reimplementation of the React Bits "slide to confirm" interaction: a handle that plants and spins while an action runs, then unfurls into a done pill on success or springs home with a squash and a shake on failure.

This is a demo, not a real purchase flow

Nova has no subscription or billing system yet. Sliding the handle below never contacts a server and never charges anything — it calls a mocked async function (createMockSubscription in assets/slide-commit.js) that resolves or rejects on a timer, standing in for the real payment call this component would eventually make. This page exists only at this direct URL and is not linked from the site's navigation.

Try it

Slide the handle to the end of the track to commit. Use the controls below to choose which outcome the mock call produces.
